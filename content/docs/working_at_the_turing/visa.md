# Visa Reimbursement

## Skilled Worker visa

The last Skilled Worker visa applications within REG happened in early 2023.

If you need a visa to work at the Turing, the Turing will reimburse (part of) the cost of the visa application.
The full [Relocation and Visa Policy](https://mathison.turing.ac.uk/page/2270) can be found on Mathison, and details should be obtained from HR directly.
You must apply for reimbursement within a certain time frame (currently a year).

Reimbursement claims used to be done on Certify, but this system is no longer in use.
It is almost certain that the current procedure is to submit an expense claim via ERPx.
The appropriate project code used to be `U-HRD-001` on Certify; on ERPx this will be `10087`.
However, you should confirm this with HR.

Note that visa applications within the UK are counted as a taxable benefit, so if you are already in the UK, you will get less money back than what you claimed for.

## Indefinite Leave to Remain (ILR)

The last ILR application within REG happened in July 2025.

For ILR applications, you can also get the application fee reimbursed.
To make a claim for ILR, you should get in touch with HR, who will send a form to fill in.

HR's attitude towards 'extra costs' (such as the Life in the UK test and biometric session) seems to have varied over time, so you should directly check with them whether these are covered.
